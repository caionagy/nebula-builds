# Nebula — builds de teste

Builds e atualizações do cliente Nebula. O código-fonte do jogo e os servidores não fazem parte deste repositório.

## Instalar e jogar

1. [Baixe o NebulaSetup.exe](https://github.com/caionagy/nebula-builds/releases/latest/download/NebulaSetup.exe).
2. Abra o instalador. Ele cria os atalhos **Nebula** na Área de Trabalho e no Menu Iniciar, sem exigir administrador.
3. Use o atalho Nebula para verificar atualizações e abrir o jogo.

O jogo fica em `%LOCALAPPDATA%\Programs\Nebula\game`. O launcher mostra o progresso do download, retoma transferências interrompidas e usa o patch incremental quando disponível. Quem utiliza o launcher antigo recebe a migração pela próxima atualização.

Servidor padrão de teste: **25.25.251.124**, pela mesma rede Hamachi. Ajuste o endereço na engrenagem do launcher quando necessário.

## Versões

[Notas e arquivos da versão mais recente](https://github.com/caionagy/nebula-builds/releases/latest). O pacote completo e os patches são arquivos de atualização; jogadores novos devem baixar o **NebulaSetup.exe**.

O executável ainda não tem assinatura digital; o Windows pode exibir um aviso do SmartScreen no primeiro download.
